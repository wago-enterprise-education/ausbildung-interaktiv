# Lern-Animationen Ausbildung Elektrotechnik

77 interaktive Lern-Animationen im WAGO-Design („Ausbildung-interaktiv“) für Auszubildende (M, EBT, EAT, EGS), Vorbereitung auf die Abschlussprüfung Teil 1 und 2.

- Jede Datei in `animationen/` ist eigenständig (HTML, CSS, JavaScript in einer Datei).
- Keine externen Abhängigkeiten: kein CDN, keine Web-Schriften, keine Cookies, kein Tracking, keine Netzwerkzugriffe.
- `index.html` ist die Übersichtsseite mit Suche und Filter nach Beruf (M, EBT, EAT, EGS).

## Hochladen

Den Inhalt des ZIP-Ordners so ins Hauptverzeichnis des Repositorys legen, dass `index.html`, `README.md`, `NUTZUNGSRECHT.md` und der Ordner `animationen/` direkt oben liegen (nicht in einem Unterordner). Für GitHub Pages: Settings → Pages → Branch `main`, Ordner `/ (root)`.
